1.3 Operaciones de limpieza, transformación y preparación de datos

Los datos del mundo real casi nunca llegan listos para el análisis. Contienen valores faltantes, duplicados, outliers, tipos incorrectos, inconsistencias de formato y ruido. Esta sección te enseña las técnicas esenciales para convertir datos crudos en un dataset limpio y listo para modelar o visualizar.

1. Detección y tratamiento de valores faltantes (NaN)

import pandas as pd
import numpy as np

# Detectar nulos
df.isnull().sum()                 # conteo por columna
df.isnull().mean() * 100          # porcentaje de nulos
df[df["columna"].isnull()]        # filas con nulos en esa columna

# Estrategias de tratamiento
# 1. Eliminar filas o columnas
df.dropna()                       # elimina cualquier fila con al menos un NaN
df.dropna(subset=["edad", "salario"])  # solo si faltan esas columnas
df.dropna(axis=1, thresh=0.7*len(df))  # elimina columnas con >30% nulos

# 2. Imputación
df["edad"].fillna(df["edad"].median(), inplace=True)
df["ciudad"].fillna("Desconocida", inplace=True)
df["salario"].fillna(df.groupby("ciudad")["salario"].transform("median"), inplace=True)

# 3. Interpolación (series temporales)
df["valor"].interpolate(method="linear", inplace=True)
⚠️ Cuidado Eliminar demasiados datos puede sesgar el análisis. Imputar con la media puede distorsionar la distribución. Siempre documenta la decisión tomada.

2. Duplicados

# Detectar
df.duplicated().sum()
df[df.duplicated(keep=False)]     # muestra todos los duplicados

# Eliminar
df.drop_duplicates(inplace=True)
df.drop_duplicates(subset=["email"], keep="first", inplace=True)

3. Outliers (valores atípicos)

Método IQR (Rango Intercuartílico)

Q1 = df["salario"].quantile(0.25)
Q3 = df["salario"].quantile(0.75)
IQR = Q3 - Q1
limite_inf = Q1 - 1.5 * IQR
limite_sup = Q3 + 1.5 * IQR

outliers = df[(df["salario"] < limite_inf) | (df["salario"] > limite_sup)]
df_sin_outliers = df[(df["salario"] >= limite_inf) & (df["salario"] <= limite_sup)]

Método Z-score

from scipy import stats
z_scores = np.abs(stats.zscore(df["salario"].dropna()))
df_filtrado = df[(z_scores < 3)]

4. Transformación de tipos y formatos

# Conversión de tipos
df["fecha"] = pd.to_datetime(df["fecha"], format="%Y-%m-%d", errors="coerce")
df["precio"] = pd.to_numeric(df["precio"].str.replace("$", "").str.replace(",", ""), errors="coerce")
df["categoria"] = df["categoria"].astype("category")

# Extraer componentes de fechas
df["anio"] = df["fecha"].dt.year
df["mes"] = df["fecha"].dt.month
df["dia_semana"] = df["fecha"].dt.day_name()

5. Normalización y estandarización

# Min-Max Scaling (0 a 1)
df["salario_norm"] = (df["salario"] - df["salario"].min()) / (df["salario"].max() - df["salario"].min())

# Z-score Standardization
df["salario_std"] = (df["salario"] - df["salario"].mean()) / df["salario"].std()

# Con scikit-learn (recomendado en pipelines)
from sklearn.preprocessing import MinMaxScaler, StandardScaler
scaler = StandardScaler()
df[["edad_std", "salario_std"]] = scaler.fit_transform(df[["edad", "salario"]])

6. Codificación de variables categóricas

# One-Hot Encoding
df_encoded = pd.get_dummies(df, columns=["ciudad", "genero"], drop_first=True)

# Label Encoding (para variables ordinales)
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df["nivel_edu_encoded"] = le.fit_transform(df["nivel_educativo"])

7. Creación de variables derivadas (Feature Engineering básico)

# Ejemplos comunes
df["salario_anual"] = df["salario"] * 12
df["rango_edad"] = pd.cut(df["edad"], bins=[0, 25, 35, 50, 100],
                         labels=["Joven", "Adulto joven", "Adulto", "Senior"])
df["es_cdmx"] = (df["ciudad"] == "CDMX").astype(int)

# Ratio o interacción
df["salario_por_anio_experiencia"] = df["salario"] / (df["experiencia"] + 1)

8. Pipeline de limpieza recomendado

  1. Cargar y hacer una copia de seguridad del dataset original.
  2. Explorar: info(), describe(), nulos, duplicados, distribuciones.
  3. Corregir tipos de datos y formatos de fecha/moneda.
  4. Tratar valores faltantes (decidir estrategia por columna).
  5. Eliminar o marcar duplicados.
  6. Detectar y decidir qué hacer con outliers.
  7. Crear variables nuevas útiles.
  8. Codificar categóricas si se va a modelar.
  9. Escalar variables numéricas si el algoritmo lo requiere.
  10. Validar el resultado final y documentar todos los pasos.
💡 Buena práctica Encapsula toda la limpieza en funciones o en un pipeline de scikit-learn (Pipeline + ColumnTransformer). Así el proceso es reproducible y fácil de aplicar a nuevos datos.
