1.1 Introducción a la programación avanzada con Python

Antes de sumergirnos en las bibliotecas de ciencia de datos, es fundamental dominar las características avanzadas del propio lenguaje Python. Estas herramientas nos permiten escribir código más expresivo, eficiente y mantenible.

1. Estructuras de datos avanzadas

Listas, tuplas, sets y diccionarios — uso profesional

Aunque ya conoces las estructuras básicas, en programación avanzada las usamos de forma más sofisticada: comprensión de colecciones, diccionarios anidados, sets para operaciones de conjuntos y namedtuples o dataclasses para estructuras inmutables. 

# Comprensión de listas (List Comprehension)
cuadrados = [x**2 for x in range(10) if x % 2 == 0]
# → [0, 4, 16, 36, 64]

# Diccionario por comprensión
mapa_cuadrados = {x: x**2 for x in range(5)}
# → {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# Set para eliminar duplicados y operaciones de conjuntos
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a & b)   # intersección → {3, 4}
print(a | b)   # unión → {1, 2, 3, 4, 5, 6}
print(a - b)   # diferencia → {1, 2}

Dataclasses (Python 3.7+)

from dataclasses import dataclass

@dataclass
class Producto:
    id: int
    nombre: str
    precio: float
    stock: int = 0

p = Producto(1, "Laptop", 15999.99, 12)
print(p)  # Producto(id=1, nombre='Laptop', precio=15999.99, stock=12)

2. Funciones avanzadas

Argumentos *args y **kwargs

def procesar_datos(*args, **kwargs):
    """Procesa una cantidad variable de argumentos posicionales y nombrados."""
    print("Posicionales:", args)
    print("Nombrados:", kwargs)

procesar_datos(10, 20, 30, metodo="media", redondeo=2)

Funciones de orden superior y lambdas

# map, filter, reduce
from functools import reduce

numeros = [1, 2, 3, 4, 5, 6]
pares = list(filter(lambda x: x % 2 == 0, numeros))
cuadrados = list(map(lambda x: x**2, pares))
suma = reduce(lambda a, b: a + b, cuadrados)
print(pares, cuadrados, suma)  # [2, 4, 6] [4, 16, 36] 56

Decoradores

import time
from functools import wraps

def medir_tiempo(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        inicio = time.perf_counter()
        resultado = func(*args, **kwargs)
        fin = time.perf_counter()
        print(f"{func.__name__} tardó {fin - inicio:.4f} s")
        return resultado
    return wrapper

@medir_tiempo
def calcular_factorial(n):
    return 1 if n <= 1 else n * calcular_factorial(n-1)

calcular_factorial(20)

3. Generadores e iteradores

Los generadores permiten crear secuencias de forma lazy (bajo demanda), ahorrando memoria cuando trabajamos con grandes volúmenes de datos. 

def generar_cuadrados(n):
    for i in range(n):
        yield i ** 2

# Uso
for valor in generar_cuadrados(5):
    print(valor)  # 0 1 4 9 16

# Generator expression
suma_grandes = sum(x**2 for x in range(1_000_000))

5. Buenas prácticas (PEP 8 y más allá)

  • Nombres descriptivos en snake_case para variables y funciones.
  • Docstrings en todas las funciones y clases públicas.
  • Type hints (anotaciones de tipo) para mayor claridad.
  • Evitar efectos secundarios inesperados; preferir funciones puras cuando sea posible.
  • Usar virtual environments y requirements.txt.
from typing import List, Dict, Optional

def calcular_media(valores: List[float]) -> Optional[float]:
    """
    Calcula la media aritmética de una lista de números.
    
    Args:
        valores: Lista de números flotantes.
    
    Returns:
        La media o None si la lista está vacía.
    """
    if not valores:
        return None
    return sum(valores) / len(valores)
