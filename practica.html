💻 Práctica: Laboratorio de Programación Avanzada y Manipulación de Datos

Esta práctica está diseñada para que apliques de forma guiada todos los conceptos del Tema 1. Trabajarás con un dataset realista de empleados y realizarás limpieza, transformación y análisis exploratorio.

📦 Archivo de la práctica

Descarga o clona el repositorio y abre el notebook en Jupyter Lab / Jupyter Notebook o en Google Colab.

⬇️ Descargar practica_tema1.ipynb Abrir en Google Colab

Ruta en el repositorio: notebooks/practica_tema1.ipynb

Objetivos de la práctica

  • Repasar sintaxis avanzada de Python (comprensiones, funciones, generadores).
  • Crear y manipular arrays con NumPy de forma vectorizada.
  • Cargar, explorar y filtrar datos con Pandas.
  • Realizar un pipeline completo de limpieza de datos.
  • Generar variables derivadas y preparar el dataset para análisis posteriores.
  • Documentar cada paso (buenas prácticas de reproducibilidad).

Estructura del notebook

Sección Contenido Tiempo estimado
0. Configuración Importaciones y configuración del entorno 5 min
1. Python avanzado Ejercicios de comprensiones, decoradores y generadores 20 min
2. NumPy Creación de arrays, operaciones vectorizadas y broadcasting 25 min
3. Pandas básico Series, DataFrames, selección y filtrado 30 min
4. Limpieza de datos Nulos, duplicados, outliers, tipos y feature engineering 45 min
5. Caso práctico Dataset de empleados – pipeline completo 40 min
6. Retos Ejercicios adicionales para profundizar 30+ min

Cómo ejecutar el notebook

  1. Clona o descarga este repositorio.
  2. Crea un entorno virtual (recomendado): 
    python -m venv venv
source venv/bin/activate          # Linux / macOS
# venv\Scripts\activate           # Windows
pip install numpy pandas matplotlib seaborn scipy scikit-learn jupyter
  3. Lanza Jupyter: 
    jupyter lab
# o
jupyter notebook
  4. Abre notebooks/practica_tema1.ipynb y ejecuta las celdas en orden.
📌 Evaluación de la práctica El docente evaluará:
  • Correctitud de las soluciones a los ejercicios.
  • Calidad y legibilidad del código (PEP 8, docstrings, nombres claros).
  • Completitud del pipeline de limpieza del caso práctico.
  • Documentación de decisiones tomadas (por qué se imputó de cierta forma, etc.).
