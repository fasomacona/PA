1.2 Manipulación avanzada de datos con NumPy y Pandas

NumPy y Pandas son el corazón del ecosistema de ciencia de datos en Python. NumPy aporta arrays multidimensionales de alto rendimiento; Pandas ofrece estructuras de datos tabulares (Series y DataFrames) con un API extremadamente potente para filtrado, agregación y transformación.

1. NumPy — Arrays multidimensionales

Creación de arrays

import numpy as np

# Desde listas
a = np.array([1, 2, 3, 4, 5])
b = np.array([[1, 2, 3], [4, 5, 6]])  # matriz 2×3

# Arrays especiales
ceros = np.zeros((3, 4))
unos = np.ones((2, 3))
identidad = np.eye(4)
rango = np.arange(0, 10, 2)          # [0 2 4 6 8]
lineal = np.linspace(0, 1, 5)        # 5 puntos entre 0 y 1
aleatorio = np.random.rand(3, 3)     # uniformes [0,1)

Atributos importantes

print(b.shape)      # (2, 3)
print(b.ndim)       # 2
print(b.dtype)      # int64 (o int32 según plataforma)
print(b.size)       # 6
print(b.itemsize)   # bytes por elemento

Indexación, slicing y broadcasting

# Indexación
print(b[0, 1])          # 2
print(b[:, 1])          # segunda columna → [2 5]
print(b[1, :])          # segunda fila → [4 5 6]

# Boolean indexing
mask = a > 3
print(a[mask])          # [4 5]

# Broadcasting: operaciones entre arrays de distintas formas
x = np.array([[1], [2], [3]])   # (3,1)
y = np.array([10, 20, 30])      # (3,)
print(x + y)                    # se expande automáticamente

Operaciones vectorizadas (¡evita bucles!)

# Mucho más rápido que un for de Python
arr = np.arange(1_000_000)
resultado = np.sqrt(arr) ** 2 + np.sin(arr)
⚡ Rendimiento Las operaciones de NumPy están implementadas en C. Un bucle for puro en Python puede ser 10–100× más lento. Siempre prefiere operaciones vectorizadas.

2. Pandas — Series y DataFrames

Series

import pandas as pd

s = pd.Series([10, 20, 30, 40], index=["a", "b", "c", "d"])
print(s["b"])           # 20
print(s.mean())         # 25.0

DataFrame — la estructura estrella

# Creación desde diccionario
datos = {
    "nombre": ["Ana", "Luis", "María", "Pedro", "Sofía"],
    "edad": [28, 34, 29, 41, 25],
    "ciudad": ["CDMX", "GDL", "MTY", "CDMX", "GDL"],
    "salario": [25000, 32000, 28000, 45000, 22000]
}
df = pd.DataFrame(datos)
print(df)

Exploración rápida

df.head()           # primeras 5 filas
df.tail(3)          # últimas 3
df.info()           # tipos y nulos
df.describe()       # estadísticas numéricas
df.shape            # (filas, columnas)
df.columns          # nombres de columnas
df.dtypes           # tipos de cada columna

Selección e indexación

# Por etiqueta
df.loc[0]                    # primera fila
df.loc[0:2, ["nombre", "edad"]]

# Por posición
df.iloc[0:3, 0:2]

# Filtrado booleano
df[df["edad"] > 30]
df[(df["ciudad"] == "CDMX") & (df["salario"] > 25000)]

# query (sintaxis más legible)
df.query("edad > 30 and ciudad == 'CDMX'")

Agregaciones y groupby

# Estadísticas por grupo
df.groupby("ciudad")["salario"].mean()
df.groupby("ciudad").agg({
    "edad": ["mean", "min", "max"],
    "salario": ["mean", "sum", "count"]
})

# Tablas pivote
pd.pivot_table(df, values="salario", index="ciudad", aggfunc="mean")

Combinar DataFrames

# Concatenación
pd.concat([df1, df2], axis=0)   # vertical
pd.concat([df1, df2], axis=1)   # horizontal

# Merges (joins)
pd.merge(clientes, pedidos, on="cliente_id", how="left")
# how: 'inner', 'left', 'right', 'outer'

Aplicar funciones

# apply sobre columnas o filas
df["salario_anual"] = df["salario"].apply(lambda x: x * 12)

# map para Series
df["ciudad_code"] = df["ciudad"].map({
    "CDMX": 1, "GDL": 2, "MTY": 3
})
📌 Flujo típico de trabajo
  1. Cargar datos → pd.read_csv(), pd.read_excel(), pd.read_sql()
  2. Explorar → head, info, describe, value_counts
  3. Limpiar → valores nulos, duplicados, tipos incorrectos
  4. Transformar → nuevas columnas, reestructuración, agregaciones
  5. Analizar / visualizar / modelar
